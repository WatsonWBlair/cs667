# Project 4: ML Interpretability for Heart Failure Prediction

**CS667 - Practical Data Science | Fall 2025 | Due: December 16, 2025**

## Overview

This project builds classification models to predict heart failure mortality and applies interpretability techniques to explain model predictions. The focus is on understanding **why** models make predictions, not just **what** they predict.

**Dataset**: Heart Failure Clinical Records (UCI ML Repository)
- 299 patients, 13 clinical features
- Target: `DEATH_EVENT` (binary classification)
